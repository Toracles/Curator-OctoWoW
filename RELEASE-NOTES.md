## Voix Mythic via SoftSpoken

- Nouvelle option désactivée par défaut. Le premier extrait est une réplique anglaise de Thrall avec des sous-titres en français ou en anglais.
- Si SoftSpoken est absent, occupé ou en pause, ou si la carte ne dispose pas d’extrait, Curator utilise sa voix habituelle.
- Le ZIP inclut le script de préparation. Voir le README pour extraire l’audio depuis une installation de SoftSpoken Stories avec FFmpeg.
- Pour une première installation, extrais le [ZIP de base](https://github.com/Toracles/Curator-OctoWoW/releases/tag/v0.2.0-alpha.2), puis applique ce correctif cumulatif avec le jeu fermé.

## Mythic voices via SoftSpoken

- A new option, off by default. The first clip is an English line from Thrall with English or French captions.
- Curator uses the original voice if SoftSpoken is absent, busy or paused, or if the card has no installed clip.
- The patch ZIP includes the preparation script. See the README for extracting the clip from an installed copy of SoftSpoken Stories with FFmpeg.
- For a first installation, extract the [base ZIP](https://github.com/Toracles/Curator-OctoWoW/releases/tag/v0.2.0-alpha.2), then apply this cumulative patch with the game closed.
