## Options Curator dans le dialogue de l’aubergiste

Sur le client 1.12.1, les options Curator apparaissent dans le dialogue original, sous les options de l’aubergiste. Elles utilisent les boutons du jeu et sont intégrées à son défilement. Le panneau de remplacement a désormais un fond sombre et opaque, notamment si un autre addon affiche le dialogue.

Les 221 scripts compilent en Lua 5.0. Le test simulé couvre les clics, le rafraîchissement du dialogue, la fermeture et le passage par le panneau de remplacement. Le rendu reste à vérifier en jeu.

Installer [le ZIP de base alpha.2](https://github.com/Toracles/Curator-OctoWoW/releases/tag/v0.2.0-alpha.2), puis appliquer ce correctif cumulatif dans `Interface/AddOns`. Si Curator est déjà installé depuis le ZIP de base, appliquer directement le correctif et taper `/reload`.
